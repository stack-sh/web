# 예제 갤러리

작은 다이어그램에서 시작해 그룹, 레이아웃 제약, 클라우드 제공자 아이콘, 프로덕션 수준의 시스템으로 단계적으로 확장합니다. 아래의 모든 썸네일은 공개 Stack 명세에 고정된 canonical source에서 생성됩니다.

Provider 예제의 아트워크는 caller-owned입니다. 브랜드 아이콘이 필요하면 표시된 아이콘 팩을 설치하세요. 팩이 없어도 같은 소스는 유효하며 Stack의 deterministic missing-icon fallback으로 렌더링됩니다.
